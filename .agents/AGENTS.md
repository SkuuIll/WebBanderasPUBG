# FlagForge Studio - Protocol & Workspace Rules

## Metodología y Protocolo de Desarrollo (Fable + Graphify + Engram)
1. **Revisar Contexto (Engram + Graphify)**: Consultar decisiones previas y evaluar la estructura de dependencias entre `index.html`, `js/app.js`, `js/db.js`, `js/platforms_db.js`, `js/symbols_db.js` y `tests/run-tests.mjs`.
2. **Razonar y Planificar (Fable)**: Pensamiento analítico de senior engineer, tónicamente directo, sin rodeos ni código superfluo.
3. **Ejecutar**: Modificaciones limpias, modulares y compatibles con PWA vanilla JS.
4. **Verificación Estricta**: Ejecutar `npm test` obligatoriamente tras cualquier cambio en el proyecto.
